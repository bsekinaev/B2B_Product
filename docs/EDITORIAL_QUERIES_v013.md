# V013-04D — поисковые запросы

## Назначение

Формирование поисковых запросов для детерминированного
fallback товарной карточки.

## Исходное состояние

- 20 товаров, по 3 запроса;
- третьим запросом часто становилось общее поле `тип`;
- категория изделия не влияла на выбор параметра.

## Изменение

Создан `app/grounded_queries.py`.

Алгоритм использует:

1. Название конкретного товара.
2. Производителя и явно указанный тип.
3. Запрос на характеристики.
4. Приоритетное название технического параметра.
5. Запрос о вариантах исполнения, только если во входных
   характеристиках присутствует пометка `варианты серии`.

Приоритет параметров зависит от категории.

Дубли удаляются после нормализации регистра и пробелов.
В запросы не вставляются неподтверждённые значения
опциональных интерфейсов или характеристики иных вариантов.

Если невозможно сформировать минимум три уникальных
запроса, генератор не должен считать fallback пригодным.

## Область действия

Изменён только детерминированный fallback.

Поисковые запросы, полученные непосредственно от GigaChat,
по-прежнему проходят действующую валидацию и не
перезаписываются без отдельного основания.

## Проверки

- 20 контрольных товаров;
- 3–5 уникальных запросов;
- отсутствие новых предупреждений валидатора;
- неизменность структурированных технических характеристик;
- проверка полного маршрута `generate_card()` с fake provider;
- контроль альтернативных исполнений и RS-485;
- сохранение HTTP-контракта.

Генератор не выполняет поиск частотности запросов и не
утверждает, что запросы оптимальны по реальному спросу.

Ручная редакторская оценка остаётся обязательной.
