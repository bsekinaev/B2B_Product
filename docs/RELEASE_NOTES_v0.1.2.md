# B2B Product Content Generator — v0.1.2

Я усилил проверку содержания карточек и их технических характеристик, добавил устойчивую обработку недостаточных данных и отрицаний, контроль значений, безопасный fallback и отдельную проверку качества генерации.

Для повторной проверки подготовил манифест из 20 реальных приборов. Все 20 прошли формальный live-gate через GigaChat; сохранённые ответы остаются локальными и требуют редакторской вычитки.

После нагрузочной проверки 10 одновременных HTTP-запросов с персональным ключом GigaChat добавил ограничение на один активный вызов модели в одном процессе. С подменённой моделью API обработал все десять запросов, реальный провайдер отклонил девять из десяти ответом HTTP 429.

Пересмотрел группировку характеристик в резервном SEO-тексте: погрешности и времена опроса не называются конструктивными свойствами. В сохранившихся live-артефактах старые тексты не исправлял задним числом.

Главные ограничения: формальный PASS не гарантирует предметную точность; в сериях требуется выбор модификации; текст fallback может оставаться похожим на техническую выписку; ограничитель конкурентных вызовов не распределён между процессами. Сервис не предназначен для открытой публикации без отдельной аутентификации и контроля квот.
