# LLM-08 — заключительный защитный патч v0.1.3

## Исходное доказательство

В LLM-07 для ОВЕН ТРМ202 был сохранён `seo_source=llm_grounded`, несмотря на три ошибки первоначального ответа: `ТРДМ202` в поисковых запросах вместо `ТРМ202`, неподтверждённое регулирование двух **независимых** параметров и вывод об удалённом мониторинге/управлении только из факта наличия `RS-485`. Формальная приёмка этого не обнаружила. `ready_for_review` никогда не означает разрешение на публикацию.

## Исправление

- `app/editorial_claims.py`: узкие детерминированные предупреждения для трёх указанных дефектов.
- `app/validation.py`: подключение проверок к единому независимому валидатору, который вызывается в том числе до `llm_grounded`, после refinement и в fallback.
- `tests/test_llm08_final_guard_v013.py`: офлайн-регрессии на буквальном ответе LLM-07, положительные контрольные случаи с исходными подтверждениями, интеграционные проверки, что ошибочный черновик не проходит гибридный маршрут.

Неподтверждённые сведения **не исправляются автоматически**, чтобы не скрывать исходную ошибку. Никакого изменения строгой схемы JSON, лимитов GigaChat, таблицы характеристик и статусов. Эти проверки намеренно покрывают конкретные классы ошибок и **не являются полноценным фактчекингом**. Человек по-прежнему проверяет корректность серии, исполнения и предназначения.

## Критерии закрытия

1. Ruff и форматирование, полный pytest с branch coverage ≥95%, offline HTTP acceptance, Windows/Ubuntu CI — PASS.
2. Ошибочный сохранённый ответ ТРМ202 не может получить `seo_source=llm_grounded` и автоматический `ready_for_review` за счёт простого дополнения длины.
3. На безопасном коротком тексте гибридный маршрут сохраняет работоспособность.
4. Редакторский порог ≥4/5 **не считается доказанным** техническими тестами и требует отдельной оценки готовых текстов. Не присваивать релизу безусловный статус «редакторская приёмка PASS» без проверки человеком.

Ветка `feat/v013-editorial-quality` — только эта ветка. История `artifacts/` неизменна. Нет сетевых вызовов GigaChat.
