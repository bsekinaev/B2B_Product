# Навигация по документации проекта

**Текущая версия кода в `main`: 0.1.3.** Документация написана на русском языке; неизменяемые технические идентификаторы Python, HTTP и JSON сохраняют исходные латинские имена.

1. [Инструкция проверяющему](REVIEWER_GUIDE.md) — установка, запуск, API и тесты.
2. [Акт технической приёмки v0.1.3](ACCEPTANCE_v0.1.3.md) — фактические PASS и ограничения.
3. [Изменения v0.1.3](RELEASE_NOTES_v0.1.3.md) — состав текущей реализации.
4. [Трассировка генерации](GENERATION_TRACE_v0.1.3.md) — поля `generation_meta`, `seo_source`, `reason_codes`.

Техническая приёмка пройдена, но **редакторская оценка ≥4/5 не подтверждена**. Любая карточка требует ручного контроля до публикации.
