# V013-03B — совместимость вариантов исполнения

Модуль `app/variant_claims.py` обнаруживает четыре узких класса ошибок:

1. Утверждение об одновременной доступности HART и RS-485,
   если источник перечисляет их как альтернативы серии.
2. Объединение настенного и DIN-реечного монтажа
   в одну модификацию.
3. Безусловное утверждение об аналоговом выходе 4–20 мА,
   если он зависит от исполнения.
4. Перенос марок материалов SS316L / ADC12 между
   мембраной и корпусом.

Правила применяются только при наличии соответствующих
структурированных характеристик в исходном товаре.

Нейтральное перечисление альтернатив не считается ошибкой.
Это консервативный фильтр, а не полная проверка совместимости.

Ограничения: проверяются только явно перечисленные
формулировки, типы устройств, варианты монтажа и марки
материалов. Неизвестная формулировка может быть пропущена.

При предупреждении существующий валидатор возвращает
`requires_revision`. Характеристики товара не изменяются.
Исторические live-файлы не перезаписываются.

Приёмка: тесты, Ruff, branch coverage >=95%,
офлайн HTTP и повторная проверка 20 карточек.
