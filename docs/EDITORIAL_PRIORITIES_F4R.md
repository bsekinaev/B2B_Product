# V013-04E-F4R — редакторские приоритеты B2B-карточек

Состояние: локальный патч, до коммита и повторной экспертной приёмки.
Основание: аудит F4 коммита `cf5e191` (3,75/5 против порога 4,00/5).

## Область изменений

- Для категории измерительных приборов порядок вводных SEO-критериев,
  коммерческих критериев и технического поискового уточнения выбирается
  **из имеющихся ключей `product.specs`**, а не по порядку входного JSON.
- Измерительные каналы/входы, сигналы и выходы идут перед питанием,
  интерфейсом, частотой, временем опроса и погрешностями.
- Длинные названия полей не превращаются в трудночитаемые запросы,
  если уже есть более короткие и предметные поля в том же источнике.
- Полные технические разделы, значения характеристик, оговорки об исполнениях,
  `generation_meta`, HTTP-контракт, URL и структура ответа не изменяются.
- Механический манометр, термометр и преобразователи давления сохраняют
  свои существующие отраслевые правила; это предотвращает регрессию
  для РОСМА с длиной SEO на нижней границе 801 символ.

## Предохранители

1. `--preview` создаёт патч только в памяти и сверяет **20 продуктов** через
   `generate_card` с фальшивым провайдером, не подключая GigaChat.
2. Нельзя применять патч, если HEAD не соответствует `cf5e191...`, ветка
   не `feat/v013-editorial-quality` или рабочее дерево содержит изменения.
3. При ошибке Ruff/pytest/HTTP после применения исходные файлы восстанавливаются,
   а новые тесты и документы удаляются.
4. В Git ничего не коммитится и не отправляется; `main`, артефакты старых
   генераций и результаты реальных LLM-вызовов не меняются.

## Acceptance

- 20/20 статус `ready_for_review`, предупреждения 0, `specs` идентичны входу,
  каждый исходный параметр встречается в SEO ровно один раз.
- 800–1200 символов SEO, 3–5 уникальных запросов, отсутствие `(серия)`.
- Проверки предметных приоритетов для ТРМ202, ТРМ500, ТРМ151, СИ8,
  2ТРМ1 и избыточных названий погрешностей ТРМ10/ТРМ500.
- Ruff, полные тесты с branch coverage ≥95%, `pip check`, offline HTTP.
- После CI **обязательна ручная повторная оценка восьми контрольных карточек**:
  среднее ≥4/5, оценка фактов каждого ≥3/5, 0 критических ошибок.

Важно: даже при зелёных автоматических проверках `ready_for_review`
не является разрешением публиковать карточку без редактора.
