# V013-03A — предметные защитные проверки

Добавлены узкие правила для обнаруженных при редакторском аудите дефектов.

## Что проверяем

1. Типы выходных устройств Р/К/С/Т/И/У нельзя называть режимами.
2. DIN-реечный монтаж нельзя объединять с настенным.
3. Новые явно названные области применения требуют исходного подтверждения.
4. Отрицательные утверждения не подтверждают положительное назначение.
5. Опциональный RS-485 нельзя представлять обязательным.

Предметные предупреждения добавляются в существующий список `warnings`.
При наличии предупреждений валидатор возвращает `requires_revision`.

## Границы проверки

Правила распознают ограниченные языковые конструкции и не заменяют
сверку с паспортом прибора. Они могут не обнаружить перефразированную
ошибку и не подтверждают совместимость конкретных вариантов исполнения.

Для поддержки областей применения учитываются описание и некоторые
структурированные поля назначения. Температура окружающей среды сама
по себе не доказывает возможность регулирования температуры.

Результаты из `artifacts/live_batch/` не изменяются.
Запуск регрессионных тестов не вызывает GigaChat.

## Приёмка

- Новые негативные и позитивные сценарии PASS.
- Полный pytest без регрессий.
- Branch coverage не ниже 95%.
- Ruff lint и format PASS.
- Офлайн HTTP-приёмка PASS.

## Уточнение для манометров

Название или характеристика `тип: манометр` подтверждает,
что прибор относится к измерению давления.

Это предотвращает ложное срабатывание на корректной
формулировке о контроле давления в batch runner.

Уточнение не подтверждает измерение температуры, уровня,
расхода и другие функции.

Сама по себе принадлежность к типу прибора также
не доказывает применимость в конкретной технологической
системе. Для этого необходимы дополнительные источники.
