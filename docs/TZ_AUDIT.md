# Аудит исходного технического задания

Проверено по PDF «AI-помощник для подготовки товарных описаний» и состоянию тега `v0.1.0` от 3 ноября 2026 года.

## Подтверждённые требования

| Требование PDF | v0.1.0 | Изменения в этой ветке |
|---|---|---|
| Входной JSON или веб-форма | POST /generate | Без изменений |
| Вызов LLM API | GigaChat | Без изменений |
| SEO-заголовок до 70 символов | Валидируется | Без изменений |
| SEO-описание 800–1200 символов | В live-примерах 290/412, не выполнено | Резервный черновик по источнику, при отсутствии commercial_note |
| Характеристики только из входа | PASS | Без изменений |
| 3–5 поисковых запросов | Контроль количества | Без изменений |
| Commercial: кому и для чего | Пуст в двух live-примерах | Нейтральный блок для специалиста по подбору |
| Недостаток данных: явная пометка | Статусы, missing_fields, warnings | Без изменений |
| Обработка ошибок, отсутствие ключей в коде | PASS | Без изменений |
| Пример двух результатов | Только скрипт экспорта, два полных результата не включены в Git | **Не закрыто** до проверенного live-прогона |
| Исходный манометр DM 02 / Манотомь | В демо был МП-01 | Пример восстановлен из PDF |
| README, промпты, ограничения | Есть | Аудит дополнен |
| Простота запуска | Чистый checkout PASS | GitHub Actions |

## Что нужно перепроверить до подтверждения полного выполнения

1. Выполнить live-генерацию по двум исходным примерам на этой ветке. Резервный текст проходит структурные проверки в тестах, но это **не подтверждает** качество реального ответа.
2. Прочитать оба текста целиком. Проверить рекламные обещания, соответствие назначения и корректность объяснения характеристик.
3. После редакторского подтверждения добавить два обезличенных результата в репозиторий как примеры. Не публиковать реальные паспорта и закрытые данные.
4. Уточнить у заказчика второй товар: в PDF дан только JSON-пример DM 02.
   Для второго воспроизводимого примера использовано документированное исполнение
   БТ-51.211 «РОСМА». [Источник производителя](https://rosma.spb.ru/termometers/seriya_211_obschetehnicheskie_tylnoe/):
   раздел «Карта заказа», пример `БТ-51.211 (0–100 °C) G½.100.1,5`.
   Это **не означает**, что работодатель предоставил этот товар. Поставку, цену,
   актуальность заказа и полные паспортные параметры отдельно не утверждаем.
5. Провести финальный прогон всех тестов и линтера в CI.

## Ограничение

Резервный шаблон описывает исходные технические факты и процесс подбора. Он не утверждает совместимость, сертификацию или эффективность изделия, но тоже требует ручного редакторского просмотра. Наличие 800–1200 символов **не равно** технической достоверности или маркетинговому качеству.
