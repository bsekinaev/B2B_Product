# V012-06B — пакетная live-приёмка 20 карточек

## Цель

Получить 20 различных товарных карточек через реальный GigaChat.
Сохранить исходный JSON, результат, ссылку на производителя,
проверки качества и происхождение SEO-текста.

## Текущее состояние

В манифесте 20 исходных товаров.
Фактические характеристики проверяются по источникам производителя.

Предыдущий агрегированный отчёт двух live-прогонов не содержит
полных текстов и не заменяет сохранённые результаты batch runner.

## Безопасность

Обычный запуск выполняет только dry-run.
Только --confirm-live разрешает сетевые обращения.

За один запуск допускается от 1 до 3 новых товаров.
На товар — максимум 2 логических вызова generate_text.
Дополнительные сетевые повторы SDK учитываются отдельно.

При ошибке выполнение останавливается.
Сохранённая попытка автоматически не повторяется.

Полные результаты хранятся в artifacts/live_batch/,
который исключён из Git.

## Запуск без сети

python -m scripts.run_live_batch

## Запуск с реальным GigaChat

python -m scripts.run_live_batch --confirm-live --max-items 2

## Требования к карточке

- HTTP 200 и status=ready_for_review
- SEO-заголовок 1–70 символов
- SEO-описание 800–1200 символов
- 3–5 поисковых запросов
- коммерческий блок заполнен
- warnings и missing_fields пустые
- характеристики сохранены
- минимум один вызов LLM зафиксирован
- ручная редакторская проверка обязательна

model_seo_text_retained означает совпадение SEO-описания
с одним из ответов модели, но не подтверждает качество смысла.

## Критерий завершения

20 уникальных товаров, 20 сохранённых успешных live-результатов,
проверенные источники характеристик и редакторская приёмка.


## Контролируемый повтор неуспешной попытки

Проверка без сети:

python -m scripts.run_live_batch --retry-id owen_2trm0 --max-items 1

Реальный повтор, только после отдельного решения оператора:

python -m scripts.run_live_batch --confirm-live --retry-id owen_2trm0 --max-items 1

Повтор допустим только для первой попытки с content_quality=FAIL.
SHA входных данных должен совпадать с первой попыткой.
Успешные карточки повторно не генерируются.

Первая попытка сохраняется под именем <id>.json.
Повтор сохраняется под именем <id>.attempt-002.json.
До обращения к модели создаётся <id>.attempt-002.started.json.

Если процесс завершился аварийно после создания started-файла,
автоматический повтор блокируется. Не удаляйте этот файл до
ручного разбора инцидента и фактического расхода токенов.

На текущем этапе допускается только одна повторная попытка.
Полный текст и результат сохраняются в artifacts/, вне Git.
