## Проверенный функционал

- Приём и строгая валидация JSON через FastAPI.
- GigaChat SDK для текстовых полей, с ограниченным редакторским повтором.
- Характеристики результата копируются из входа без переписывания LLM.
- Проверяются SEO-заголовок (до 70 символов), SEO-описание (800–1200 символов), 3–5 поисковых запросов и коммерческий блок.
- При недостаточных исходных данных или неподтверждённых утверждениях выдаётся бизнес-статус и предупреждения.
- При подходящем наборе исходных характеристик доступен детерминированный fallback.

## Два материала для сдачи

- Манометр МЕТЕР ДМ 02 (серия): SEO-описание 1131 символов, статус ready_for_review.
- Термометр РОСМА БТ-51.211: SEO-описание 1063 символа, статус ready_for_review.

В обоих JSON сохранены исходные технические характеристики, 3 поисковых запроса, коммерческий блок и отсутствие предупреждений формального валидатора.

**Критически важно:** это самостоятельно подобранные примеры, не два полного товара работодателя. Результаты получены при offline replay записанных ответов GigaChat и deterministic fallback; коммерческие блоки позднее перегенерированы через fake provider без новых live вызовов. Детали и ссылки на исходные каталоги — examples/submission/provenance.json. ready_for_review означает обязательную ручную проверку; это не одобрение публикации.

## Что было проверено в реальном GigaChat

Ранее выполнялись реальные обращения к GigaChat на демонстрационных и каталоговых товарах. Некоторые ответы не достигали нужной длины SEO или содержали неподтверждённые свойства. Успешная live-quality gate на текущем релизе **не доказана**. Текущая офлайн-приёмка доказывает формат/API-поведение и качество deterministic fallback на выбранных примерах, но не качество всех будущих ответов GigaChat.

## Ограничения

1. Числовая и regex-валидация не заменяет проверку связи каждого свойства с фактическим источником; ошибочная привязка числа может быть пропущена.
2. Параметры с пометкой «варианты серии» не определяют конкретную модификацию; её нужно выбрать перед закупкой.
3. Недостаточные исходные данные не позволяют честно сформировать описание 800–1200 символов.
4. Сервис рассчитан на локальное использование, без аутентификации внешних клиентов, API-квот, хранения состояния и CMS-публикации.
5. В релизе v0.1.1 нет CI-конфигурации в main; успешные запуски Actions относились к другим коммитам. Исправление запланировано в v0.1.2.
6. Код интеграции реальной LLM и показатели производительности требуют отдельных live и нагрузочных испытаний.
