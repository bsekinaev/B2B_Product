## Реализованный функционал

- JSON API на FastAPI.
- Интеграция GigaChat.
- SEO-заголовок и SEO-описание.
- Поисковые запросы и коммерческий блок.
- Сохранение исходных характеристик.
- Независимая проверка сгенерированного текста.
- Редакторский повтор и детерминированный fallback.
- Контролируемые статусы и предупреждения.

## Примеры для сдачи

**МЕТЕР ДМ 02 (серия)** — SEO-описание 1131 символ,
статус ready_for_review.

**РОСМА БТ-51.211** — SEO-описание 1063 символа,
статус ready_for_review.

Это самостоятельно подобранные товары, а не два полных
паспорта, предоставленных работодателем.

Результаты подготовлены с использованием offline replay
записанных ответов GigaChat и детерминированного fallback.
Коммерческие блоки обновлены локально с fake provider.

Новые сетевые вызовы GigaChat при финальном обновлении
коммерческих блоков не выполнялись.

Происхождение примеров:
`examples/submission/provenance.json`.

## Ограничения

Статус ready_for_review не означает разрешения на публикацию.

Существующая проверка чисел не гарантирует правильной связи
числа с конкретной характеристикой.

Для товаров-серий необходимо выбирать конкретное исполнение.

При недостатке фактов допустимый SEO-текст длиной
800–1200 символов не гарантируется.

Публичная эксплуатация API без аутентификации и квот
не предусмотрена текущей версией.

Успешный live-quality gate именно для v0.1.1
не подтверждён опубликованными результатами.
